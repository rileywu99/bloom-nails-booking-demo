# Bloom Nails booking (demo build)

Live demo: https://rileywu99.github.io/bloom-nails-booking-demo/

This repo holds only the static, pre-built files of a demo version of a
private booking app for a nail salon. The source code is not here.

In the demo, the services come from sample data, open times are worked out in
your browser with the real scheduling rules, and confirming a booking saves
nothing and sends nothing. The live app checks a Google Calendar for busy
times, creates the calendar event, and emails a confirmation plus a reminder
the day before.
